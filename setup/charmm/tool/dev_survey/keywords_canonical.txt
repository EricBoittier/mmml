# CHARMM canonical compile-time keywords
#
# Source of truth: tool/cmake/prefx_keywords.cmake (the only place the build
# turns tokens into -DKEY_<NAME>=1 compile definitions; see CMakeLists.txt
# lines 1295-1314 and 1755-1760).
#
# This is the UNION of every token that any list(APPEND keywords ...) block
# can add, across all configuration branches. The "[cond]" tag notes the
# enclosing if() guard; tokens with no tag are always present (base list).
#
# NOTE on REMOVE_ITEM: NODISPLAY and NOGRAPHICS appear only as REMOVE_ITEM
# targets (lines 247). NOGRAPHICS IS in the base list (line 6). NODISPLAY is
# never APPENDed anywhere -> it is NOT a canonical keyword (the REMOVE_ITEM of
# NODISPLAY is a no-op). See keywords_junk.md.
#
# QUANTUM/QCHEM/MOLVIB/MMFF are REMOVE_ITEM'd in gamess/nwchem branches but are
# legitimately APPENDed elsewhere, so they remain canonical.
#
# pref.dat (tool/profiling/pref.dat) is the LEGACY prefx keyword file used only
# by the old profiling tool; it contains stale tokens (EM64T, I4BINARY, HUGE,
# FEWMFC, NEWTIMER, GNU/UNIX/EXPAND/PUTFCM) and is NOT authoritative for the
# CMake build. Not merged into this list.
#
# source/util/keywords.F90 / keywords.inc.in are GENERATED from the cmake list
# at configure time (configure_file), so they add nothing new.
#
